# Model Miniaturization Experiment

条件付きひらがな拡散モデルのパラメーター数を削減し、生成品質をどこまで維持できるか検証する実験です。9フォント・46文字を扱う4,754,817パラメーターの基準モデルに対し、200,000パラメーター未満の軽量モデルを比較します。

## 評価項目

- 64×64グレースケール画像を生成できること
- 文字条件に対応したひらがなを判別できること
- 個別のフォント条件を生成結果へ反映できること
- raw重みとEMA重みの差
- 教師画像の幾何変形が軽量モデルへ与える影響
- パラメーター削減後も基準モデルに近い品質を維持できるか

## 比較基準

| 項目 | 9フォント基準モデル |
|---|---:|
| 画像サイズ | 64 × 64 |
| 文字条件 | 46 |
| フォント条件 | 9 |
| 教師画像 | 41,400枚 |
| パラメーター数 | 4,754,817 |
| 学習更新数 | 32,400 |
| 最終loss | 0.005915 |

基準モデルのEMA生成では、多くの文字を判別でき、フォントごとの太さや筆画差も確認できました。

## 第1モデル

演算とチャンネル数を大幅に削減した最初の軽量モデルです。

| 項目 | 値 |
|---|---:|
| channels | 8 / 16 / 24 |
| condition dimension | 32 |
| パラメーター数 | 73,721 |
| 基準モデルからの削減率 | 約98.4% |
| 教師画像 | 幾何変形あり41,400枚 |
| epochs | 100 |
| 学習更新数 | 32,400 |
| 最終loss | 0.033445 |
| 推論 | 50-step DDIM |

構成は通常の畳み込み、ReLU、平均プーリング、最近傍拡大、Embedding、全結合です。正規化、滑らかな時刻表現、負値を保持する活性化を除いたことで、パラメーター数は小さくなりました。

### 結果

- raw・EMAとも背景ノイズを除去できなかった
- 一部に文字らしい筆画は現れたが、ひらがなとして安定して判別できなかった
- 同じ文字に対する9フォントの出力がほぼ同一で、フォント条件の利用も不十分だった
- EMAだけの追従不足ではなく、モデル構成または表現力の不足と判断した

## 第2モデル

第1モデルの失敗を踏まえ、200,000未満の範囲で容量と学習安定性を増やしました。

| 項目 | 値 |
|---|---:|
| channels | 16 / 32 / 48 |
| condition dimension | 48 |
| パラメーター数 | 166,657 |
| 基準モデルからの削減率 | 約96.5% |
| 基準モデルとの比率 | 約1 / 28.5 |
| 活性化 | LeakyReLU 0.1 |
| 時刻表現 | sin/cos embedding + MLP |
| 正規化 | BatchNorm |
| downsampling | average pooling |
| upsampling | nearest neighbor |

BatchNormは推論用モデルを書き出す際に直前の畳み込みへ統合できる配置に限定しています。

### 幾何変形あり

| 項目 | 値 |
|---|---:|
| 教師画像 | 41,400枚 |
| 平行移動 | ±4 px |
| scale | 0.9〜1.1 |
| 回転 | ±3° |
| batch size | 128 |
| epochs | 100 |
| 学習更新数 | 32,400 |
| 最終loss | 0.014352 |

EMAによってノイズは大きく減り、線やフォントの太さを部分的に表現できました。一方、ひらがなとしての判別は難しく、特定の文字条件が全フォントで共通して破綻しました。

### 幾何変形なし

| 項目 | 値 |
|---|---:|
| 教師画像 | 46文字 × 9フォント = 414枚 |
| 平行移動・回転 | なし |
| scale | 1.0 |
| batch size | 128 |
| epochs | 8,100 |
| 学習更新数 | 32,400 |
| 最終loss | 0.013807 |

元画像を各条件1枚へ限定しても、学習時刻とノイズは読み出すたびに新しく生成されます。幾何変形あり実験と更新数を揃え、教師分布だけを単純化しました。

EMA生成は筆画状の出力を増やしましたが、特定の文字条件が全フォントで繰り返し破綻しました。幾何変形の除去だけでは、基準モデルと同等の文字判別能力を維持できていません。

## 現時点の結論

4,754,817から166,657パラメーターへの約96.5%削減には成功しましたが、生成品質は維持できませんでした。

ただし、第2モデルでは次の中間的な改善を確認しています。

- EMAによる背景ノイズの低減
- 白背景と黒い筆画の生成
- 文字条件ごとに異なる形状
- 太字フォントなど一部のフォント特徴

破綻が文字列単位で全フォントに共通するため、主な課題はフォント条件よりも、文字条件とノイズ除去を同時に表現する容量・最適化にあると考えられます。

## 次の比較

変形なし414枚を維持し、batch sizeを128から64へ下げます。各教師画像を見る回数は8,100回で揃えるため、更新数は増加します。

| 項目 | Batch 128 | Batch 64 |
|---|---:|---:|
| epochs | 8,100 | 8,100 |
| batches per epoch | 4 | 7 |
| 総更新数 | 32,400 | 56,700 |
| learning rate | 0.0002 | 0.0002 |
| 状態 | 完了 | 未実行 |

```bash
python scripts/train.py \
  --config configs/train.miniature-canonical-b64.json
```

Batch 64で改善した場合は、勾配平均の粒度と更新数の両方が変化するため、必要に応じて総更新数を揃えた追加実験で要因を分離します。
